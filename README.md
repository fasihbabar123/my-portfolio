## About This Project

This portfolio is part of my 35-day development plan to build practical projects, improve my GitHub profile, and prepare for junior developer roles.

The project started as a simple homepage and has been improved step by step with:

- a responsive layout
- navigation sections
- project cards
- contact form
- custom API routes
- external API integration
- Vercel deployment

## Features

- Responsive portfolio homepage
- Hero section with introduction
- About section
- Skills section
- Project cards with GitHub and live demo links
- Contact form
- Contact API route using POST requests
- Weather API demo using an external API
- Deployed live with Vercel
